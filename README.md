# daw2-parejas-pr

Web de un evento para practicar el trabajo colaborativo con Git y GitHub.

## Descripción del proyecto

Desarrollo colaborativo de una página web para unas jornadas de tecnología, utilizando ramas, Issues, Pull Requests y revisiones de código.

Se han utilizado ramas feature, Pull Requests, revisiones de código y protección de la rama main.
